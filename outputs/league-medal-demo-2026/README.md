# نمونهٔ تست مدال‌های لیگ

فایل «ورزشکاران-آزمایشی-لیگ.xlsx» شامل چهار ورزشکار ساختگی در وزن ۵۴- است.

1. یک لیگ مردان بزرگسالان بسازید و تیم‌های «تیم تست ۱» تا «تیم تست ۴» را در یک گروه ثبت کنید.
2. فایل را از بخش فهرست ورزشکاران لیگ وارد کنید.
3. مسابقهٔ هفته را بسازید، وزن‌کشی را ثبت و قرعه‌کشی را انجام دهید.
4. دو نیمه‌نهایی و فینال را ثبت و مدال‌ها و امتیازها را بررسی کنید؛ دو بازندهٔ نیمه‌نهایی برنز مشترک می‌گیرند.

این نمونه بازیکن آزاد ندارد. برای تست بازیکن آزاد، قالب جدید را از سامانه دانلود کنید، ستون تیم را خالی بگذارید و نام مربی را حتماً وارد کنید.
