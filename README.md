# سامانه وب برگزاری مسابقات تکواندو

این مخزن شامل دو برنامه است:

- `backend`: API نوشته‌شده با Go، Gin و PostgreSQL
- `frontend`: رابط وب نوشته‌شده با Vue 3، TypeScript و Vite

راهنمای کامل نصب، اجرای پروژه، ساخت حساب اولیه، URLهای کاربردی، اجرای تست‌ها و رفع خطاهای رایج در [مستند فنی اجرا](docs/technical-setup.md) قرار دارد.

اجرای روزمره در سه مرحله انجام می‌شود: PostgreSQL را اجرا کنید، بک‌اند را روی پورت `8080` بالا بیاورید و سپس فرانت‌اند را روی پورت `5173` اجرا کنید.

برای deploy روی سرور Ubuntu، پس از آماده‌سازی اولیه‌ی سرور و تنظیم `/etc/tkdhub.env` و Nginx، از SSH اجرا کنید:

```bash
sudo bash /opt/tkdhub/scripts/deploy.sh
```

این دستور شاخه‌ی `master` را به‌روز می‌کند، بک‌اند و فرانت‌اند را build می‌کند، از PostgreSQL بکاپ می‌گیرد، migrationهای pending را اجرا می‌کند، نسخه را نصب و سلامت API را بررسی می‌کند. جزئیات و نکات rollback در [راهنمای deploy](docs/deployment.md) است.
